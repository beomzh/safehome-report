# SafeHomeReport (가칭)

**매물 링크와 캡처만 넣으면 "보러 갈지"와 "대출이 대략 얼마 나오는지"를 알려 주는 로컬 도구.**

연락하거나 방문하기 전에 한 번 거르는 용도입니다. 입력은 최소한(링크·캡처, 연소득, 보유 자금)만 받고, 방문해서 등기부·건축물대장까지 확인한 뒤의 정밀 분석은 별도 화면으로 분리했습니다.
위험 판정은 계산 규칙이 하고, AI는 매물 설명에서 항목을 뽑는 데에만 씁니다. 계산은 내 PC의 브라우저 안에서만 이루어집니다.

> "탐지된 위험 신호 없음"은 안전을 보증하지 않습니다.

## 두 개의 화면

| 화면                     | 주소     | 언제                                   | 입력                                                                         | 결과                                                                                                                                   |
| ------------------------ | -------- | -------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **방문 전 점검**         | `/`      | 매물을 보고 연락·방문할지 고민할 때    | 매물 링크, 캡처 또는 설명 글, (연소득·보유 자기자금·혼인 상태)               | 보러 갈지(보러 가도 됨 / 조건부 / 권장 안 함), 대략의 최대 대출·필요 자기자금·필요 연소득, 해당될 수 있는 정책 대출, 방문 전 확인할 것 |
| **보고 온 뒤 정밀 분석** | `/after` | 방문해서 등기부·건축물대장을 확인한 뒤 | 등기부 PDF·내용, 건축물대장, 공시가격 등 (방문 전 점검 값은 자동으로 이어짐) | 권리분석, 위험 신호, 자금 계획, 상세 리포트                                                                                            |

방문 전 점검 흐름: **링크 넣기 → 캡처(⌘/Ctrl+V)나 설명 글을 붙여넣으면 AI가 바로 읽음(LLM 설정 시) → 읽은 내용 확인(틀리면 수정) → 오른쪽에 결과가 실시간으로 갱신**됩니다. AI를 쓰지 않아도 금액만 입력하면 같은 결과를 볼 수 있습니다.

## 빠른 시작

요구 사항: **Docker**(권장) 또는 **Node.js 20.16 이상**(CI·Docker 이미지는 Node 22)

```bash
git clone https://github.com/beomzh/safehome-report.git
cd safehome-report
cp .env.example .env        # 키는 선택입니다. 없어도 금액만 입력해 쓸 수 있습니다
docker compose up -d --build
```

브라우저에서 <http://127.0.0.1:3000> 을 엽니다. 포트는 내 PC(127.0.0.1)에만 열리고, 컨테이너는 non-root·읽기 전용 파일시스템으로 실행됩니다.

```bash
docker compose logs -f web   # 로그 보기
docker compose down          # 중지
```

Docker 없이 실행하려면 `npm install && npm run dev` 입니다(개발 서버는 `127.0.0.1:3000`).

> `.env` 를 고친 뒤에는 `docker compose up -d` 로 다시 올려야 반영됩니다.

키는 **모두 선택**입니다. 없는 기능은 버튼이 안내 메시지만 보여 주고, 해당 값은 직접 입력하면 됩니다. 키는 로컬 `.env` 에만 넣고 저장소·이미지·로그에는 남기지 않습니다. 모두 **무료**입니다(LLM 제외).

### 1) 공공데이터포털 (시세·건축물대장)

1. [data.go.kr](https://www.data.go.kr) 에서 회원가입·로그인합니다.
2. 아래 **각 API 상세 페이지**에서 **활용신청**을 누릅니다. 개발계정은 **자동 승인**이고 일 10,000건까지 무료입니다. 활용 목적은 "개인 학습·계약 전 점검"처럼 사실대로 적으면 됩니다.
3. [마이페이지 → 데이터활용 → Open API](https://www.data.go.kr/iim/api/selectAPIAcountView.do) 에서 **일반 인증키**(Encoding 값)를 복사해 `.env` 의 `PUBLIC_DATA_API_KEY=` 에 붙입니다. **키 하나로 신청한 모든 API가 호출됩니다.**
4. 승인 직후 몇 분은 "등록되지 않은 서비스 키"(코드 30)가 날 수 있습니다. 잠시 뒤 다시 시도하세요.

### 2) 브이월드 (공시가격, 선택)

1. [vworld.kr](https://www.vworld.kr) 에서 회원가입·로그인합니다.
2. [오픈API → 인증키 발급](https://www.vworld.kr/dev/v4dv_apikey_s001.do) 에서 신청합니다. 사용자 구분은 **개인**, 서비스 URL(도메인)은 **`localhost`** 로 적습니다(내 PC에서만 쓰므로). 기업명 칸이 필수로 보이면 "개인"이라고 적으면 됩니다.
3. 발급된 키를 `VWORLD_API_KEY=` 에, 등록한 도메인을 `VWORLD_DOMAIN=` 에 넣습니다(기본값 `localhost`). 도메인이 다르면 `INCORRECT_KEY` 가 납니다.
4. 사용하는 서비스는 부동산(NED) **공동주택가격속성조회**입니다. 개발자 문서는 [vworld 오픈API](https://www.vworld.kr/dev/v4api.do).

### 3) LLM (AI 추출 등, 선택)

OpenAI 호환 엔드포인트(Responses 또는 Chat Completions 형식)를 씁니다. [OpenAI](https://platform.openai.com/api-keys), Azure OpenAI, 로컬 서버 등 호환되는 곳이면 됩니다.

```bash
LLM_PROVIDER=openai-compatible
LLM_BASE_URL=<…/responses 또는 …/chat/completions 전체 주소>
LLM_API_KEY=<발급받은 키>
LLM_MODEL=<모델 또는 배포 이름>
```

- 이미지(캡처)를 읽으려면 **비전을 지원하는 모델**이어야 합니다.
- LLM을 켜면 **버튼을 눌렀을 때만** 붙여넣은 설명·캡처가 그 서버로 전송됩니다. 보내는 항목은 [데이터 흐름](docs/data-flow.md) 참고. 캡처에 연락처·이름이 보이면 가리고 찍으세요.

## 주요 기능

- **방문 전 점검**: 링크·캡처만으로 방문 추천 결론, 대략의 최대 대출·필요 자기자금·필요 연소득, 해당될 수 있는 정책 대출(기본금리 포함)을 실시간으로 보여 줍니다. 시세는 공공 실거래 중앙값으로 자동 조회합니다.
- **매물 설명·캡처 AI 추출 (선택)**: 유형·보증금·단지명·주소·전용면적·주택 유형을 읽어 입력칸에 바로 채웁니다(틀리면 고칠 수 있음). 주소에서 법정동코드를 찾아 시세 조회까지 이어집니다. 링크의 내용은 읽지 않습니다.
- **정책 대출 추천**: 연소득·보유 자금·혼인 상태 등으로 주택도시기금 대출의 해당 여부와 소득·금액 구간 금리를 공식 요건·금리표 기준으로 안내하고, 필요 조건 계산에 그 상품의 한도·금리를 씁니다. 시중은행 평균금리도 은행연합회 공시로 보여 줍니다.
- **보고 온 뒤 정밀 분석**: 등기부(PDF·직접 입력·붙여넣기) 권리분석, 건축물대장 용도, 공시가격, 경매 시 회수 가능액 시나리오, 세금·수수료 계산, 상세 리포트 시트(인쇄 가능).
- **정직한 판정**: 정보가 부족하면 안전 대신 **판단 보류**로 표시하고, "안전"이라는 결과는 내지 않습니다.

## 지금 되는 것과 안 되는 것

- 실거래 시세 조회는 **아파트·연립다세대(빌라)·오피스텔·단독다가구 매매**를 모두 실제 응답으로 검증했습니다(아파트 외에는 신뢰도를 낮게 표시하고, 단독다가구는 건물명이 없어 연면적 ±20%·법정동명으로 추정). 유형별 API는 데이터포털에서 따로 활용신청해야 합니다.
- **등기부 PDF**: 텍스트가 들어 있는 PDF 는 브라우저 안에서만 읽어 입력칸을 채웁니다(서버 전송 없음, 공개된 실제 열람본 2건으로 확인). **스캔본(이미지) PDF 는 선택 기능인 "AI 로 스캔본 읽기"로 읽을 수 있지만, 등기부 쪽 이미지(소유자 성명·주소 등 개인정보)가 LLM 서버로 전송**되고 모델이 글자를 틀리게 옮길 수 있습니다(동의 체크가 있어야 눌림, 결과에 항상 "원문과 대조" 경고). 합성 스캔본으로만 확인했습니다. 취소선만 있는 말소 표시는 구분하지 못합니다(말소 등기 행으로 판단). 채워진 값을 원문과 대조하세요.
- **매물 링크의 내용은 읽지 않습니다.** 플랫폼 약관·차단 때문에 링크에서는 사이트와 매물 번호만 인식하고, 항목은 붙여넣은 설명이나 캡처에서 추출합니다. 매물 링크를 입력하면 오른쪽 사이드바에서 사이트를 볼 수 있습니다(네이버·호갱노노는 표시를 막아 새 창으로 엽니다).
- **재산세는 공시가격을 넣으면 잠정값으로 계산하지만, 종합부동산세는 계산하지 않습니다.** 재산세 세율표는 2차 자료 기준이고 세부담상한을 반영하지 않으며, 종부세는 세제 개편이 진행 중입니다.
- 취득세는 **일반 세율**만 계산합니다. 다주택·조정대상지역 중과와 감면은 반영하지 않으며, 중과 세율은 직접 입력할 수 있습니다. 중개보수 요율표는 서울시 조례 원문을 확인하지 못해 **잠정값**입니다.
- 판단 기준 일부(예: 보증금/시세 70%·80%)는 공식 자료로 검증되지 않은 **잠정값**입니다. 리포트에도 같은 안내가 나옵니다.
- **AI 기준값 제안은 확실하지 않은 값을 비워 둡니다.** 실제로 시험해 보니 DSR 40%·기간 30년 정도만 채우고 LTV·금리는 "판단하지 못함"으로 답하는 경우가 많았습니다. 빈 칸은 직접 입력하세요.
- **대출 금리와 대출 대상 요건은 확인일(2026-11-09~11-12) 기준 공식 안내를 옮긴 것**이며 수시로 바뀝니다. 주택도시기금 상품은 `npm run rates:check` 로 현재 공식 값과 비교할 수 있습니다. 시중은행은 은행연합회 비교공시의 은행별 평균금리(신용점수 구간별, 실제 적용 금리와 다를 수 있음)와 기준금리(COFIX)를 보여주고, 신생아 특례의 특례 종료 후 금리는 담지 않았습니다. 자세한 내용은 [docs/loan-rates.md](docs/loan-rates.md). 계산용 LTV·DSR·금리는 직접 입력하거나 "예시 값 채우기"(공식 값 아님)·AI 제안을 씁니다.

진행 상황은 [로드맵](docs/ROADMAP.md)에서 봅니다.

## FAQ

<details>
<summary>링크만 넣으면 왜 분석이 안 되나요?</summary>

앱이 매물 사이트의 페이지를 대신 열어 읽는 것은 약관과 차단 문제로 하지 않습니다. 매물 화면의 설명을 복사하거나 화면을 캡처해 붙여넣으면 AI가 항목을 뽑아 줍니다. 설명 없이 링크만 입력하면 서버를 호출하지 않고 화면에서 안내만 합니다.
</details>

<details>
<summary>왜 "안전"이라는 결과가 없나요?</summary>

입력한 정보로는 위험 신호를 찾지 못해도 안전을 보증할 수 없습니다. 그래서 위험 신호가 없으면 "탐지된 위험 신호 없음"으로, 정보가 부족하면 "판단 보류"로 표시하고, 계약 당일과 잔금 전 등기부 재확인을 안내합니다.
</details>

<details>
<summary>내 정보는 어디로 가나요?</summary>

위험 점검과 자금 계산은 브라우저 안에서만 실행됩니다. 서버로 나가는 것은 네 가지(시세 조회는 매매·전월세 모두 같은 값)와, 직접 동의했을 때만 쓰는 스캔본 등기부 AI 읽기뿐이고 모두 직접 버튼을 눌렀을 때만 전송됩니다. 시세 조회는 법정동코드·전용면적·단지명·법정동명을 공공데이터포털로, 항목 추출은 붙여넣은 매물 설명과 첨부한 캡처를 LLM 서버로(텍스트의 전화번호·이메일은 제거, 이미지는 제거 불가), 기준값 제안은 계약 유형·보증금(매매가)·지역·보유 주택 수·생애최초 여부를, AI 해석은 계약 유형·기준표 결론·기준별 상태와 비율(금액·자산·소득·가격은 제외)을 LLM 서버로 보냅니다. 성명·금액·재무 정보·등기부 내용은 보내지 않고 서버 로그에도 남기지 않습니다. 자세한 내용은 [위협 모델](docs/threat-model.md)을 보세요.
</details>

<details>
<summary>로그는 어떻게 보나요?</summary>

`docker compose logs -f web` 으로 봅니다. 요청 번호·소요 시간·건수·결과만 한 줄 JSON 으로 남습니다. 형식과 `LOG_LEVEL` 은 [docs/operations.md](docs/operations.md)에 있습니다.
</details>

## 개인정보와 보안

- 분석 계산은 브라우저에서만 실행됩니다. 방문 전 점검의 입력은 "보고 온 뒤" 화면으로 넘기기 위해 **이 브라우저 탭의 sessionStorage** 에만 잠시 보관되고(탭을 닫으면 사라짐) 서버로 보내지 않습니다. 체크리스트의 체크 상태만 브라우저에 영구 저장합니다.
- 서버로 나가는 것은 직접 한 동작뿐입니다: 시세·건축물대장·공시가격 조회(지역코드·면적·단지명·지번), AI 추출(붙여넣은 설명·캡처). **방문 전 점검 화면에서는 캡처나 글을 붙여넣는 순간 LLM 으로 전송**되고(직접 타이핑한 글은 "다시 추출" 버튼을 눌러야 전송), 정밀 분석 화면은 버튼을 눌러야 전송됩니다. 성명·금액·재무 정보·등기부 내용은 보내지 않고 로그에도 남기지 않습니다.
- 키·엔드포인트는 로컬 `.env` 에만 두며 저장소와 이미지에는 들어가지 않습니다(`.gitignore`, `.dockerignore`).
- 위험 판정은 계산 규칙이 하고 AI는 판정하지 않습니다. AI 출력은 형식·범위를 검증하고, 확신하지 못하는 값은 비워 둡니다.
- 서버는 `127.0.0.1` 에만 열리고 컨테이너는 non-root·읽기 전용입니다. 이미지는 `npm run scan:image`(trivy 컨테이너)로 점검합니다.

## 개발

```bash
npm run check          # 타입 검사 + 린트 + 테스트
npm run build          # 프로덕션 빌드
npm run format:check   # 포맷 검사
npm run rates:check    # 정책 대출 금리가 공식 사이트 현재 값과 같은지 점검(읽기 전용)
npm run rates:banks    # 은행연합회 공시에서 시중은행 평균금리 갱신
npm run scan:image     # 컨테이너 이미지 취약점 스캔 (이미지를 먼저 빌드)
npm run review:experts # LLM 2단계 검토(공인중개사·법무사 관점, LLM 키 필요)
```

위험 판정 규칙은 `src/core`(순수 함수), 화면은 `src/web`·`src/app`, 외부 호출은 `src/adapters` 에 있습니다. 기여·커밋·릴리즈 규칙은 [CONTRIBUTING](CONTRIBUTING.md)에 있습니다. 라이선스는 [MIT](LICENSE).
