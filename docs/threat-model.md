# 위협 모델 (초안, STRIDE 요약)

## 자산

등기부 원문·성명, 자산·연소득·기존 대출, 분석 이력, 공공데이터 API 키, LLM 엔드포인트·키.

## 신뢰 경계

```
[사용자 PC: 브라우저 ↔ 로컬 컨테이너(앱, SQLite)]
        │                       │
        ├── 공공데이터 API (외부, 주소·법정동 등 조회 키만 전송)
        └── LLM 엔드포인트 (사용자가 지정, 정규화된 facts 화이트리스트만 전송)
```

## 위협과 대응

| 분류        | 위협                                                       | 대응                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정보 노출   | 등기부 원문·성명·자산이 LLM/외부로 전송됨                  | LLM 입력 화이트리스트, 전송 페이로드 필드 검사 테스트, 공유 사본 마스킹                                                                                                                                                                                                                                                                                                                                                                                                   |
| 정보 노출   | 로그에 개인정보 기록                                       | 로그 PII 금지, 주소·성명 해시/마스킹, 로그 PII 누출 테스트                                                                                                                                                                                                                                                                                                                                                                                                                |
| 정보 노출   | 키·엔드포인트·실제 등기부 샘플이 공개 저장소·이미지에 포함 | `.env` 주입, `.gitignore`/`.dockerignore`, 마스킹 샘플만 커밋, 커밋 전 secret-scan, 이력 점검                                                                                                                                                                                                                                                                                                                                                                             |
| 변조        | 외부 텍스트(매물 설명)로 LLM 출력 조작(prompt injection)   | LLM 판정 권한 없음, 출력 스키마 검증, 등급·수치 불일치 시 폐기, 주입 회귀 테스트                                                                                                                                                                                                                                                                                                                                                                                          |
| 변조        | 잘못된 파싱(말소 누락 등)으로 오판                         | 파싱 신뢰도·원문 위치 표시, 신뢰도 미달 시 판단 보류, 파서 골든 테스트                                                                                                                                                                                                                                                                                                                                                                                                    |
| 서비스 거부 | 공공API 한도 초과·장애                                     | 캐시, 쿼터 카운터, 타임아웃·재시도, 수동 입력 폴백                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 권한 상승   | 컨테이너 탈취                                              | non-root, 포트 `127.0.0.1` 바인딩, 이미지 취약점 스캔                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 정보 노출   | 시세 조회 시 입력이 서버·외부로 전송됨                     | `/api/market` 은 법정동코드·전용면적·단지명·법정동명만 받는다(성명·금액·재무 정보 제외). 키는 서버 환경변수에만 있고 응답·로그·오류 메시지에 남기지 않는다. 키 미포함 테스트·이미지 검사                                                                                                                                                                                                                                                                                  |
| 신뢰·오용   | AI 가 안전·승인을 단정하는 문장을 씀                       | 프롬프트로 금지하고, 출력에서 코드(`guard.ts`)가 "안전합니다"·"대출이 됩니다" 같은 단정 문장을 버린다(AI 해석·기준값 제안). 숫자는 입력에 있는 것만 통과                                                                                                                                                                                                                                                                                                                  |
| 정보 노출   | 스캔본 등기부 이미지가 LLM 서버로 전송됨 (개인정보 포함)   | 기본은 전송 없음. 텍스트 없는 스캔본에서만 "AI 로 스캔본 읽기"가 나타나고 개인정보 전송 안내와 동의 체크를 해야 버튼이 눌린다. 이미지는 브라우저에서 쪽당 JPEG(가로 1500px 이하, 최대 8쪽)로만 보내고 서버는 형식·개수·크기를 검증한다. 로그에는 요청 번호·쪽 수·글자 수만 남기고 이미지·글자는 남기지 않는다. 이미지 속 글자는 신뢰할 수 없는 데이터로 취급하도록 프롬프트에 명시하고, 결과는 판정이 아니라 로컬 파서가 읽는 텍스트일 뿐이며 오타 가능성을 항상 경고한다 |
| 정보 노출   | 건축물대장 조회 시 주소가 서버·외부로 전송됨               | 사용자가 버튼을 눌렀을 때만 전송. `/api/building` 은 시군구 코드·주소 일부(법정동 찾기용)·지번만 받고 성명·금액·재무 정보는 받지 않는다. 로그에는 요청 번호·건수·결과만 남기고 주소·지번은 남기지 않는다                                                                                                                                                                                                                                                                  |
| 정보 노출   | 매물 설명이 LLM 서버로 전송됨                              | 사용자가 버튼을 눌렀을 때만 전송, 전화번호·이메일 제거, 길이 제한(6,000자). 성명·재무 정보·등기부 내용은 이 경로로 받지 않는다. 매물 텍스트·키·주소는 로그에 남기지 않는다                                                                                                                                                                                                                                                                                                |
| 변조        | 매물 설명 안의 지시문(prompt injection)으로 추출값 조작    | `<listing>` 구획 + 시스템 프롬프트 지시, 출력 스키마·범위 검증, 사용자 확인 후 적용, 판정은 룰 엔진이 수행                                                                                                                                                                                                                                                                                                                                                                |
| 정보 노출   | 기준값 제안 시 입력이 LLM 서버로 전송됨                    | 사용자가 버튼을 눌렀을 때만 전송. 보내는 필드는 계약 유형·보증금(매매가)·지역(50자)·보유 주택 수·생애최초 여부뿐이며 소득·자산·성명·재무 정보는 보내지 않는다. 로그에는 지역·금액을 남기지 않는다                                                                                                                                                                                                                                                                         |
| 변조        | AI 가 틀린 규제 값을 사실처럼 제안                         | 모르면 null, 신뢰도 high 금지, 범위 검증, 사용자 확인 후 적용, 적용한 칸을 리포트에 "AI 제안"으로 표시                                                                                                                                                                                                                                                                                                                                                                    |
| 변조        | 지역 입력란의 지시문(prompt injection)                     | `<request>` 구획과 시스템 프롬프트, 50자 제한, 출력 스키마·범위 검증, 판정은 룰 엔진                                                                                                                                                                                                                                                                                                                                                                                      |
| 부인        | 어떤 룰·버전으로 판정했는지 불명                           | 리포트에 `rulesetVersion`, `asOf`, 프롬프트 해시 기록                                                                                                                                                                                                                                                                                                                                                                                                                     |

위 표는 구현 진행에 맞춰 갱신한다 (PR 체크리스트 항목).
