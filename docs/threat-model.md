# 위협 모델 (초안, STRIDE 요약)

## 자산

등기부 원문·성명, 자산·연소득·기존 대출, 분석 이력, 공공데이터 API 키, LLM 엔드포인트·키.

## 신뢰 경계

```
[사용자 PC: 브라우저 ↔ 로컬 컨테이너(앱, SQLite)]
        │                       │
        ├── 공공데이터 API (외부, 주소·법정동 등 조회 키만 전송)
        └── LLM 엔드포인트 (사용자가 지정, 정규화된 facts 화이트리스트만 전송)
```

## 위협과 대응

| 분류        | 위협                                                       | 대응                                                                                          |
| ----------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 정보 노출   | 등기부 원문·성명·자산이 LLM/외부로 전송됨                  | LLM 입력 화이트리스트, 전송 페이로드 필드 검사 테스트, 공유 사본 마스킹                       |
| 정보 노출   | 로그에 개인정보 기록                                       | 로그 PII 금지, 주소·성명 해시/마스킹, 로그 PII 누출 테스트                                    |
| 정보 노출   | 키·엔드포인트·실제 등기부 샘플이 공개 저장소·이미지에 포함 | `.env` 주입, `.gitignore`/`.dockerignore`, 마스킹 샘플만 커밋, 커밋 전 secret-scan, 이력 점검 |
| 변조        | 외부 텍스트(매물 설명)로 LLM 출력 조작(prompt injection)   | LLM 판정 권한 없음, 출력 스키마 검증, 등급·수치 불일치 시 폐기, 주입 회귀 테스트              |
| 변조        | 잘못된 파싱(말소 누락 등)으로 오판                         | 파싱 신뢰도·원문 위치 표시, 신뢰도 미달 시 판단 보류, 파서 골든 테스트                        |
| 서비스 거부 | 공공API 한도 초과·장애                                     | 캐시, 쿼터 카운터, 타임아웃·재시도, 수동 입력 폴백                                            |
| 권한 상승   | 컨테이너 탈취                                              | non-root, 포트 `127.0.0.1` 바인딩, 이미지 취약점 스캔                                         |
| 부인        | 어떤 룰·버전으로 판정했는지 불명                           | 리포트에 `rulesetVersion`, `asOf`, 프롬프트 해시 기록                                         |

위 표는 구현 진행에 맞춰 갱신한다 (PR 체크리스트 항목).
