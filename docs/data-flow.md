# 데이터 흐름

이 앱에서 **내 PC 밖으로 나가는 데이터**를 기능별로 정리합니다. 아래 표에 없는 계산(위험 점검·자금 계산·필요 조건·리포트)은 모두 브라우저 안에서만 실행되고 어디로도 전송되지 않습니다. 모든 전송은 사용자가 해당 버튼을 눌렀을 때만 일어납니다(링크 입력 후 사이드바 표시는 아래 별도 항목).

```
브라우저 (입력·계산·리포트)
   │  버튼을 눌렀을 때만
   ▼
로컬 서버 (127.0.0.1:3000, Docker)  ── API 키·LLM 설정은 여기에만 있음(.env)
   ├──▶ 공공데이터포털 (data.go.kr)     시세·전월세 조회
   └──▶ 내가 지정한 LLM 엔드포인트        AI 추출·제안·해석
```

## 버튼별 전송 내용

| 버튼                 | 로컬 서버 경로                     | 전송 대상      | 전송하는 값                                                                                    | 보내지 않는 값                       |
| -------------------- | ---------------------------------- | -------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------ |
| 실거래가로 시세 조회 | `GET /api/market`, `GET /api/rent` | 공공데이터포털 | 법정동코드(시군구 5자리)·전용면적(또는 연면적)·단지명·법정동명·주택 유형                       | 성명·금액·재무 정보·등기부·주소 원문 |
| 건축물대장 조회      | `GET /api/building`                | 공공데이터포털 | 시군구 코드·주소(법정동을 찾기 위한 텍스트)·지번                                               | 성명·금액·재무 정보·등기부           |
| AI로 항목 추출       | `POST /api/listing`                | LLM            | 붙여넣은 매물 설명(전화번호·이메일 제거, 6,000자까지)·링크의 플랫폼 힌트·첨부한 캡처(최대 4장) | 성명·재무 정보·등기부 내용           |
| AI로 기준값 제안받기 | `POST /api/assumptions`            | LLM            | 계약 유형·보증금(매매가)·지역(50자)·보유 주택 수·생애최초 여부                                 | 소득·자산·성명                       |
| AI 해석 요청         | `POST /api/verdict`                | LLM            | 계약 유형·기준표 결론·기준별 상태와 비율                                                       | 금액·자산·소득·가격·성명·지역        |

- **캡처 이미지는 전화번호 같은 개인정보를 제거할 수 없습니다.** 연락처·이름이 보이면 가리고 캡처하세요.
- 로컬 서버 로그에는 요청 번호·소요 시간·건수·결과만 남고 위 값들은 남지 않습니다([운영 가이드](operations.md#로그-보기)).
- 공공데이터포털 키는 로컬 서버에서만 붙이고 브라우저·응답·로그에 노출하지 않습니다.
- `LLM_PROVIDER=none`(기본)이면 AI 기능은 전송 없이 안내 메시지만 보여줍니다. `PUBLIC_DATA_API_KEY` 가 없으면 시세 조회도 같습니다.

## 사이드바(사이트 보기)

매물 링크를 입력하면 오른쪽 사이드바가 그 사이트를 **내 브라우저가 직접** 불러옵니다(iframe). 이 경우 데이터 흐름은 이 앱이 아니라 해당 사이트와 내 브라우저 사이이며, 사이트의 쿠키·추적 정책을 따릅니다. 앱은 프레임 안의 내용을 읽지 않고, 주소를 `Referer` 로 보내지 않으며(`referrerPolicy=no-referrer`), 입력한 값을 그 사이트로 보내지 않습니다. 네이버 부동산·호갱노노는 프레임을 막아 열지 않고 새 창 링크만 제공합니다.

## 브라우저에 저장되는 것

- 체크리스트 진행 상태와 테마 선택만 브라우저(`localStorage`)에 저장됩니다. 입력값·분석 결과·재무 정보는 저장하지 않으며 새로고침하면 사라집니다.
- 서버에는 DB·파일 저장이 없습니다(메모리 캐시는 같은 지역·월의 공공데이터 응답만, 6시간).
