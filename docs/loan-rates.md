# 대출 상품 금리 안내 데이터

화면의 "이용할 수 있는 대출 종류"에 나오는 금리는 [`rules.config/loan-rates.json`](../rules.config/loan-rates.json) 에서 옵니다. **공식 사이트에서 확인한 값만** 출처 링크와 확인일을 붙여 담고, 확인하지 못한 부분은 `notCovered` 로 화면에 그대로 밝힙니다. 금리는 수시로 바뀌므로 이 문서와 데이터는 확인일(2026-11-09) 기준입니다.

## 확인하지 못한 것

- **일반 버팀목·신혼부부 전세자금·디딤돌의 소득·보증금(또는 대출기간)별 칸 금리표**: 공식 페이지의 표 값이 텍스트로 추출되지 않았습니다. 범위와 우대·가산 규칙만 담았고 화면에 그 사실을 표시합니다.
- **시중은행의 실제 전세대출·주택담보대출 금리**: 은행별 가산금리·우대금리·보증기관·신용도에 따라 달라 공식 자료로 확인하지 못했습니다. COFIX 기준금리만 제공합니다.
- **월세 관련 대출, 신생아 가구 대상 상품**: 금리를 확인하지 못해 데이터가 없습니다(화면은 "공식 자료를 확인하지 못했습니다"로 안내).
- 상품별 한도·소득·자산 요건은 이 데이터의 범위가 아닙니다.

조사 과정에서 웹 페이지 본문을 요약 도구로 가져왔기 때문에, 숫자는 **공식 페이지 원문과 한 번 더 대조**하는 것이 안전합니다(링크 제공). 보금자리론은 같은 페이지의 이전 공시(2026-11-01, 0.1%p 낮음)와 검색에서 본 10월 표와 값이 서로 일관됨을 확인했습니다.

## 화면 동작

- 상품마다 금리, 가산·우대 규칙, **출처 링크와 확인일**을 보여줍니다.
- 확인일이 **35일**을 넘으면 "확인한 지 N일이 지났습니다. 금리가 바뀌었을 수 있으니 다시 확인하세요" 경고를 띄웁니다(`STALE_AFTER_DAYS`).
- 데이터가 없는 상품은 "공식 자료를 확인하지 못했습니다. 취급 기관의 안내 금리를 확인하세요"로 안내합니다.

## 데이터 갱신 방법

자동 갱신은 없습니다. 월 1회 정도 직접 확인하고 갱신하세요.

1. 위 표의 출처 링크에서 현재 금리를 확인하고 `rules.config/loan-rates.json` 의 값과 `source.checkedAt`(필요하면 `publishedAt`)을 고칩니다. 보금자리론은 매월 공시되고 COFIX 는 매월 15일경 공시됩니다.
2. `npm test` 를 실행합니다. 스키마가 **공식 도메인이 아닌 출처**(블로그 등), https 가 아닌 링크, 0 이하·15% 초과 금리, 만기 수와 금리 수가 다른 표를 거부합니다.
3. 이 문서의 표와 확인일도 함께 고칩니다.
