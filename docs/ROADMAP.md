# 로드맵 (작업 단위)

상세 요구사항은 [PRD](PRD.md), 결정 배경은 [ADR](adr/) 참고. 진행 상태: `[x]` 완료 / `[ ]` 대기.

## M0 — 검증 spike (사람 확인이 필요한 항목)

- [ ] 공공데이터 API 키 발급, 실거래가·건축물대장·공시가격 엔드포인트·한도·이용조건 확인
- [ ] 중개업 조회 API·HUG 명단 조회 가능 여부 확인 (불가 시 안내 문구로 대체)
- [ ] LTV 임계치(현재 70/80% 잠정)와 소액임차인 최우선변제 기준 금액의 공식 근거 확인
- [ ] 대출 규제 기준(LTV 한도 테이블, DSR, 스트레스 금리, 규제지역), 취득세·중개보수·보증료율 확인
- [ ] 사용할 LLM 엔드포인트 규격(인증, OpenAI 호환 여부, 호출 한도, 컨텍스트)과 전송 허용 데이터 범위 확인
- [ ] 개인정보를 제거한 실제 등기부 PDF 샘플 수집
- [ ] PDF 라이브러리 비교(pdf.js vs pdfplumber) — 말소선·표 추출 정확도
- [ ] 매물 플랫폼 자동 수집 가능 여부(약관) 확인
