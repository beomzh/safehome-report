# ADR-0006: 웹 UI는 core를 브라우저에서 직접 실행

- 상태: 승인
- 날짜: 2026-11-04

## 맥락

입력(성명, 금액, 등기부 내용)은 민감 정보다. core의 `evaluateRisk` 는 순수 함수라 서버 없이 실행할 수 있다. 공공API·LLM 호출처럼 키가 필요한 기능만 서버(로컬 컨테이너)가 필요하다.

## 결정

- M3 웹 UI는 폼 입력을 `buildRiskInput` 으로 검증·변환한 뒤 **브라우저에서 `evaluateRisk` 를 호출**한다. 이 단계에서는 입력이 네트워크로 나가지 않는다.
- 룰 설정(`rules.config/rules.v1.json`)은 번들에 포함해 로드 시 스키마로 검증한다.
- 서버 API 라우트는 키가 필요한 공공API 프록시(M4)와 LLM 호출(M5)에만 둔다. 이 경로로 보내는 필드는 위협 모델의 화이트리스트를 따른다.
- 판정 기준일은 UI에서 오늘 날짜로 주입한다(core는 시각을 읽지 않는다, ADR-0003).
- 체크리스트 체크 상태만 `localStorage` 에 저장한다(개인정보 없음). 저장소 접근 실패 시에도 화면은 정상 동작한다.

## 결과

- 오프라인·로컬에서도 판정이 동작하고 서버 로그에 입력이 남지 않는다.
- 공공API·LLM을 붙일 때 브라우저→서버 전송 필드를 명시적으로 늘리는 변경이 되므로 PR 체크리스트(위협 모델 갱신) 대상이 된다.
