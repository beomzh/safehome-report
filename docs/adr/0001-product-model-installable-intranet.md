# ADR-0001: 제품 모델 — 설치형, 사내망 전용

- 상태: 승인
- 날짜: 2026-11-04

## 맥락

등기부등본·자산·소득 등 민감 정보를 다룬다. 호스팅 SaaS는 개인정보 처리 책임·로그 정책·운영 비용이 따른다. 사용자 환경은 외부(공공데이터 API) 호출이 가능하고, LLM은 사내 모델(사내망 한정)을 쓴다.

## 결정

- 사용자가 Docker로 자기 PC에서 실행하는 **설치형**으로 만든다. 데이터는 로컬 볼륨(SQLite)에만 저장한다.
- v1 배포 범위는 **사내망 사용자**로 한정한다. 이미지는 사내 컨테이너 레지스트리로만 배포하고, 저장소는 private을 유지한다.
- 외부 호출은 공공데이터 API와 사내 LLM 엔드포인트뿐이다.
- 호스팅 SaaS·사외 공개는 v1 범위 밖이다.

## 결과

- 개인정보가 사용자 PC 밖으로 나가지 않는다는 보장을 단순하게 유지할 수 있다.
- 사내 엔드포인트·키가 이미지·저장소에 들어가지 않도록 `.env` 주입과 secret-scan이 필수다.
- 사용자마다 공공데이터 키를 발급해야 하고 Docker 설치 장벽이 있다.
