# ADR-0004: 금액 표현과 룰 설정 관리

- 상태: 승인
- 날짜: 2026-11-04

## 맥락

금액 계산에 부동소수점 오차가 생기면 안 된다. 임계치·세율·대출 규제 기준은 자주 바뀌고 출처가 불확실한 값이 많다.

## 결정

- 금액은 **원 단위 정수**(`Number.isSafeInteger`)만 허용한다. 소수·음수·범위 초과는 입력 스키마에서 거부한다. 비율(%)은 표시·임계치 비교용으로만 계산한다.
- 임계치·기준 금액·세율은 코드에 두지 않고 `rules.config/*.json` 에 둔다. 각 값은 `source`(출처)와 `status`(`provisional`/`verified`)를 가지며 zod 스키마로 검증한다.
- `provisional` 값은 M0에서 공식 자료와 대조해 `verified` 로 바꾼다. 룰·임계치가 바뀌면 `rulesetVersion` 을 올리고 릴리즈 노트에 명시한다.
- 룰 결과와 리포트에 `rulesetVersion`, 판정 기준일(`asOf`)을 기록한다.

## 결과

- 판정이 바뀌는 변경을 설정 변경으로 추적할 수 있다.
- 현재 값(LTV 70/80% 등)은 모두 잠정치이며, 공식 근거 없이 검증된 것처럼 표시하지 않는다.
