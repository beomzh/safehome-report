# ADR-0003: 결정적 core, LLM은 보조

- 상태: 승인
- 날짜: 2026-11-04

## 맥락

위험 판정은 재현 가능하고 근거를 설명할 수 있어야 한다. LLM이 도구를 자율 호출하면 결과가 달라지고 테스트가 어렵다. 매물 설명 같은 외부 텍스트는 prompt injection 경로가 될 수 있다.

## 결정

- 위험 판정·점수·대출 계산은 `src/core` 의 **순수 함수**(룰 엔진)가 한다. LLM은 판정에 관여하지 않는다.
- LLM은 (a) 매물 텍스트에서 필드 추출(사용자 확인 전제), (b) 룰 결과의 문장화에만 쓴다.
- `src/core` 는 I/O(fs, 네트워크)와 `adapters/web/mcp` 에 의존하지 않는다. ESLint `no-restricted-imports` 로 강제한다.
- 현재 시각도 core 내부에서 읽지 않고 `asOf` 로 주입받는다(결정성).
- MCP는 core 함수를 노출하는 얇은 어댑터(`src/mcp`)로 두고, MCP 없이도 파이프라인이 동작해야 한다.
- LLM 출력은 스키마 검증을 거치고 실패하면 템플릿 문장으로 대체한다.

## 결과

- 골든셋 테스트로 판정을 회귀 검증할 수 있다.
- 입력이 부족하면 Green 대신 `inconclusive`(판단 보류)가 된다.
