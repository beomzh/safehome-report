# ADR-0001: 제품 모델 — 설치형(로컬 실행), 공개 저장소

- 상태: 승인
- 날짜: 2026-11-04

## 맥락

등기부등본·자산·소득 등 민감 정보를 다룬다. 호스팅 SaaS는 개인정보 처리 책임·로그 정책·운영 비용이 따른다. 개인 프로젝트이며, LLM 엔드포인트 같은 환경 값은 사용자가 로컬 실행 때만 입력한다.

## 결정

- 사용자가 Docker로 자기 PC에서 실행하는 **설치형**으로 만든다. 데이터는 로컬 볼륨(SQLite)에만 저장한다.
- 소스는 **공개 저장소**에 둔다. 단, 키·엔드포인트·모델명 등 환경 값과 실제 등기부·재무 자료는 저장소와 이미지에 절대 포함하지 않는다. (`.env` 로만 주입, `.gitignore`/`.dockerignore` 로 차단)
- 외부 호출은 공공데이터 API와, 사용자가 `.env` 로 지정한 LLM 엔드포인트(선택)뿐이다.
- 호스팅 SaaS는 v1 범위 밖이다.

## 결과

- 개인정보가 사용자 PC 밖으로 나가지 않는다는 보장을 단순하게 유지할 수 있다.
- 공개 저장소이므로 커밋 전 secret-scan, 마스킹된 샘플만 커밋, 문서에 내부 시스템 이름·주소를 쓰지 않는 규칙이 필수다.
- 사용자마다 공공데이터 키를 발급해야 하고 Docker 설치 장벽이 있다.
