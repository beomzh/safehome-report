# ADR-0005: LLM 공급자 — 선택 기능, Provider 인터페이스

- 상태: 승인 (연동 규격은 M0에서 확인)
- 날짜: 2026-11-04

## 맥락

LLM은 사용자가 가진 엔드포인트(OpenAI 호환 규격 가정)나 로컬 모델을 쓰므로 추가 비용을 요구하지 않는다. 어떤 엔드포인트든 사용자 PC 밖 네트워크 구간일 수 있다.

## 결정

- `LlmProvider.generate({ system, input, schema, timeoutMs }) → 검증된 JSON` 인터페이스를 두고 구현체는 `openai-compatible`, `ollama`, `anthropic` 으로 한다. 환경변수로 선택하며 기본값은 `none`(LLM 없음).
- 엔드포인트는 어떤 것이든 외부 Provider와 같게 취급한다: 전송 필드는 화이트리스트(정규화된 facts)만, 등기부 원문·성명·자산·소득은 전송하지 않는다. 사용자가 명시적으로 켠 경우에만 호출한다.
- 매물 설명 등 외부 텍스트는 "데이터" 구획으로 감싸 전달하고, LLM 출력의 등급·수치 필드가 룰 결과와 다르면 폐기한다.
- 타임아웃·동시성 제한·입력 해시 캐시를 둔다. 접속 불가·장애 시 템플릿 문장으로 폴백하며, LLM 없는 모드를 1급 기능으로 유지한다.
- 엔드포인트 주소·키·모델명은 저장소·이미지·문서에 쓰지 않고 `.env` 로만 주입한다.

## 결과

- LLM 없이도 전체 기능이 동작한다.
- 엔드포인트의 규격(인증, 호출 한도, 컨텍스트)과 제공자 정책상 전송 가능 범위는 M0에서 확정한다.
